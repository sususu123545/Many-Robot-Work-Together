# 红球抓取成功与失败的第一性原理复盘（2026-11-17）

本次仅审阅用户提供的 WorkBuddy 文档、流程图、配套源码和照片；未连接或操作真机。用户报告最终成功，文档记载偏航与两次抬升通过。以下区分“记录所报告的结果”“源码可确认的行为”和“尚待验证的物理解释”。本复盘不改变 T07 整体验收状态。

## 核心判断

最终成功最有支持的解释是：反复测量目标相对工具的位置并修正接近，使球进入有效夹持区域；随后增加闭合，在合适接触几何下建立足以抗重力的夹持。早期尝试同时存在三维对准不足、执行结果判定不当和抓取验证薄弱。无法从连续修改参数的一次成功中，唯一确定各因素的贡献。

## 第一性原理

抓取必须同时满足：可达且不碰撞、真实运动到位、两侧形成有效接触、接触力足以支撑物体、物体脱离支撑后仍跟随末端。发送成功、编码器到位、接触和抓持成功是不同事件。

图像中的左右居中不唯一确定深度。相机在夹爪上方且偏后时，球的投影处于两指之间，仍可能在夹持区域前方或下方。球体上半部接触时，接触力可能含向下分量；赤道附近的两侧接触与下方的包覆几何更有利于抵抗下滑。记录没有接触点实测，不能把接触上半球当成已证明的统一根因。

简化为赤道附近对称两侧接触时，必要条件约为 2μN ≥ m(g+a)，其中 N 为每侧法向力。重量、摩擦系数、实际夹持力均未测得，故不能量化载荷裕量；也不能由某个闭合 ticks 推出固定夹持力。

## 失败与成功的因果解释

- 文档第7.2节记载模型估计误差由73.8毫米降至约10–12毫米，支持重复测量与修正有效改善接近，不能将其直接当成独立实测的绝对定位精度。
- 早期夹爪目标365、实际349，不能仅凭16 ticks差异证明已接触球；可能包含位置偏差、载荷、摩擦、保护中断或通信问题。
- 最终目标430、实际329，比早期差异明显，结合抬升与偏航后球仍在爪口，支持存在受阻接触和抓持；单看目标差仍不能区分球、地面或机构阻挡。
- 上层位置校验与有限重试可以减少“未执行却继续规划”。但未动且重发后动，不足以定位为UART丢包；缺少分层回执、串口抓取和STOP时间关联时，只能称执行未达到预期。
- 模型失准、严格阈值与早停可能阻断任务。成功时放宽到14 ticks也改变了验收尺度，因此不能把放宽阈值本身当成定位精度提高。

## 文档中应修正的归因

1. “舵机固有死区9–12 ticks”：现有证据只证明某些姿态和负载下出现该量级位置差。零偏、摩擦、回差、重力负载、采样时刻都可能参与。14 ticks约为3.36度，单关节以0.2米有效力臂估算即可产生约12毫米末端偏差；不应设为全工作空间的通用容差。
2. “串口丢包30–40%”：缺少统计分母、发送与接收侧证据，不能确认丢包层级或概率；ROS发布、控制器接受、UART写出、固件接受和实际运动应分别核验。
3. “地面错30毫米”：工具点z=-0.070与假设地面z=-0.041不是同一几何对象，还涉及球心高度、指尖外形、姿态和TCP定义。应分别标定地面平面与工具几何；看到球不提供完整避碰约束。
4. “10毫米平台就是工具中心偏置”：尚未唯一辨识。源码到位容差、相机尺度、手眼外参、IK量化和同步误差都可能造成平台。记录使用35毫米球径，而此前用户测量约38毫米；若为同一球，针孔近似Z=fD/(2r)下深度会低估约7.9%，在100–150毫米范围内约8–12毫米。
5. “四项独立证据”：深度138→93毫米与像素半径63→94若来自同一球径反推，则高度相关：138×63/94≈92.5毫米。球与工具间距也共享视觉和运动学链路，不能视为独立外部测量。固定外部侧视连续视频的离地与跟随证据更强。
6. “温度升高证明碰地”“低温证明不刮地”“50度会平台”均超出当前测量所能支持的结论。

## 配套源码揭示的成功判据缺陷

源码：原附件目录 grasp_loop.py。

- 第219–241行：循环最多10轮，未达到6毫米、未检出球或运动返回非OK时仍可能进入闭爪阶段；文档实际最小误差10.3毫米，没有达到设定6毫米。
- 第148–157行：某子步四次发送后仍未到位，后续子步仍可继续；返回名OK_WITH_x_RETRIES也掩盖了“重试耗尽仍失败”。
- 第159–168行：清空缓存后等新收到的消息，没有检查消息采样时间；新收到不等于新采样。
- 第170–183行：夹爪增量不足也判接触，未将执行失败与物体接触严格分开。
- 第249–259行：未要求抬升成功，也未要求touched为真，仅gap_after<20毫米就HELD。反例：若工具与球心起初模型重合，球留地面、工具真实上升18毫米，距离仍为18毫米，小于20毫米，会误报成功。
- 附件照片held1/held2支持球位于爪口，但手眼相机静态照片不能独立量出离地高度；配套主脚本也没有偏航验证段，需要另补对应操作记录。

这些缺陷不否定用户观察到的最终成功，但说明当前程序也允许假成功，不能作为自动数据标注的唯一依据。

## 对VLA工作的意义与下一步

这次属于传统视觉反馈、运动学和夹爪控制的工程基线验证；源码没有VLA模型推理。它证明这套硬件至少能够在该次配置下抓持该球，为演示采集提供基础，尚不证明VLA策略、定位精度或重复成功率。

建议先冻结成功配置并保留源码哈希；补测球径、真实夹持中心与地面；把执行失败、候选接触、已离地、保持完成分别记录。验收使用固定外部相机确认离地、保持与释放，保存同步图像/关节/动作/回执/STOP记录。做一组预先固定规则的重复试验，报告成功数/总数、位置分布与失败类别，再逐项对照视觉反馈、闭合终点、容差和重试策略。无效或中断演示保留并标注，不混入成功数据。
