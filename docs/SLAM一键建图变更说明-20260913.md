## 二、控制台改动明细（robot_console.html）

1. **SLAM 面板新增操作行**：开始建图 / 结束建图 / 地图名输入框（留空自动按时间戳命名）/ 保存地图 + 状态提示行。
2. **状态联动**：订阅 `/slam_control/status`（JSON，2s 心跳）。按钮使能规则——
   控制节点在线 && (开始: 未运行且不忙 / 结束+保存: 运行中且不忙)；5s 心跳超时判节点离线并提示。
3. **地图渲染聚焦**：drawMap 计算非 unknown 格的包围盒，缩放聚焦到已建区域（上限 12px/格），
   不再是"19.2m 大灰幕里一小坨"；badge 空数据时按订阅状态显示"等待地图数据…/未连接"。

## 三、车端 `slam_control` 节点（slam_control.py）

- 订阅 `/slam_control/cmd`（std_msgs/String）：`start` / `stop` / `save` / `save:<名字>`
- 发布 `/slam_control/status`（JSON、latched、2s 心跳）：`{running, busy, last, detail, ts}`
- **start**：以进程组启动 `roslaunch <全路径>/ld06_hector.launch`，日志落容器 `/home/ubuntu/hector_run.log`
- **stop**：进程组 SIGINT（6s 不死转 SIGKILL），句柄丢失时 pkill 兜底
- **save**：不依赖 map_server，节点内把缓存的最新 `/map`（OccupancyGrid）直接写成
  map_saver 同款 trinary PGM + YAML，落盘容器 `/home/ubuntu/maps/<名>.{pgm,yaml}`

## 四、开机自启（slam-control.service）

- 抄 `ld06.service` 模式：`Type=oneshot` + `RemainAfterExit=yes`，
  `After=docker.service start_node.service ld06.service`
- `ExecStartPre` 等容器内 rosmaster 就绪（最多 120s）
- 启动逻辑收进 `run_slam_control.sh`，幂等（锚定 `pgrep -f '^python3 /home/ubuntu/slam_control.py'`）

## 五、本次踩过并修复的坑（重要经验）

1. **按包名 launch 必败**：该车 devel 空间未注册 `ldlidar_stl_ros`，
   `roslaunch ldlidar_stl_ros ld06_hector.launch` 报 RLException → **必须用 launch 文件全路径**。
2. **ROS 官方源签名过期**（EXPKEYSIG F42ED6FBAB17C654）→ `ros-noetic-map-server` deb 404 装不上
   → 保存地图改为节点内 Python 直写 PGM/YAML，零新依赖。
3. **pgrep 自匹配**：service 内联命令写 `pgrep -f '[s]lam_control.py'` 会匹配到同一条 bash 命令行里
   的明文 `python3 /home/ubuntu/slam_control.py`，误判"已在跑"而跳过启动
   （服务 active 但节点没起来、节点日志为空）→ 启动逻辑进脚本文件 + 锚定匹配。
4. **控制台 PUB 缓存不随重连失效**：车重启后 rosbridge 断开重连，`PUB` 缓存的 `ROSLIB.Topic`
   还绑着旧 ros 实例 → publish 发进已关闭的 socket，日志照打实际全丢
   → `topic()` 加 `PUB[name].ros !== ros` 绑定校验，重连自动重建。
5. **雷达近距离自遮挡**：实测车头前方约 90°、0.14~0.29m 有静止遮挡回波
   （车上当前只装了雷达，遮挡物为支架/安装结构，具体待实车确认），
   0.15 的 `laser_min_dist` 挡不住 → 提高到 0.35。
   ⚠️ 副作用：车头贴墙 <35cm 时该段墙不进图，推车别怼墙根。

## 六、使用流程

1. 打开控制台（本地代理 `http://127.0.0.1:8000`）→ 小车 IP 填 `raspberrypi` → 连接
2. SLAM 面板：**开始建图**（状态行显示"hector 已启动"）→ 慢推车绕行一圈（慢、别原地猛转）
   → **保存地图**（落盘 `/home/ubuntu/maps/`）→ **结束建图**
3. 地图文件用 `docker cp` + `pi_pull.py` 取回电脑

## 七、已知限制

- **hector 静置会漂移**（实测 2 小时漂 27.9m）：建图是"启动→推车→保存→停止"的一次性动作，
  不要常驻空转；这也是它不做常驻服务、只做按需启停的原因。
- **地图目录在容器内**（`/home/ubuntu/maps/`）：容器可写层持久、重启不丢，但 `docker rm` 重建容器会丢。
- **ROS apt 源签名过期**：阶段 2 依赖包（laser-scan-matcher / amcl / move-base）装不上，
  需先换新签名密钥或走离线源码编译。
- 雷达近距离遮挡物（支架/安装结构）待实车确认与调整，当前以 0.35m 过滤兜底。
