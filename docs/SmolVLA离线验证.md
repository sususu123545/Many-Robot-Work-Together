# ArmPi Pro 的 SmolVLA 离线推理验证

> ⚠️ **球径口径（2026-11-23 补记）**：本文多处按历史 **35 mm** 计算，并有由地面接触反推的 42.3 mm。现场实测球径约 **37 mm**，后续分析请以此为基准；本文的历史数值保留原样，便于对照当时的结论。


本阶段验证“真实图片、关节反馈、任务文字能否通过预训练模型得到有限数值的动作块”，并记录加载与单次推理耗时。输入工具和推理工具均没有执行动作的代码。通过推理不能证明能够抓球，也不能证明这些动作适合 ArmPi Pro。

不需要先录制完整抓球示范。可以使用静止小车的短时传感器检查数据；这些数据不标注为成功示范，也不是训练集。

2026-11-19 已在 `sususu` 的 RTX 3090 上完成真实离线推理：完整权重严格加载通过，输入历史相机快照与真实关节读数，输出形状为 `[1, 50, 6]` 的有限动作数值。首次推理含前后处理约 0.388 秒。ArmPi 动作语义尚未适配，未执行抓取。

**2026-11-20 更正：此前结果仅证明数值前向运行成功。** 基础检查点的统计文件使用 SO100 数据域前缀，未提供当前处理器查找的 `observation.state`、`action` 统计键。旧报告里的 `checkpoint_native` 字段不能据其名称认定为已还原的机器人动作单位。历史记录保留；新版工具明确检查归一化覆盖，缺少匹配统计时将 `checkpoint_native` 设为 `null`，只保存未验证的数值输出。参见[官方仓库问题记录](https://github.com/huggingface/lerobot/issues/4415)与[固定版本处理器实现](https://github.com/huggingface/lerobot/blob/v0.7.0/src/lerobot/processor/normalize_processor.py)。

后续已从迁移前检查点恢复三组完整源域统计，并在 ycw 实测其显式覆盖生效。该修复限于原 SO100 数据坐标的数学处理；ArmPi 的实体映射仍未验证，配置不自动选择来源域，也不启用动作。见文末“源域统计恢复”。

## 已确认的输入差异

- 使用 `lerobot/smolvla_base`，固定检查点版本 `5e8d12a6e2975b0e5e5fce7c8caf47c371d257b6`，随附的官方处理器和统计文件一起加载。完整检查点包含骨干参数，关闭重复的基础 VLM 权重预加载，并强制 `strict=True`；缺少或多出权重时拒绝加载。
- 此版本的状态与动作都是 6 维。项目现有执行器接收 7 维 TCP 位移/旋转/夹爪，不能直接相接。
- 诊断输入按照 `joint1, joint2, joint3, joint4, joint5, r_joint` 排列，保留 ROS 关节反馈的弧度值。这个排列和尺度**尚未与检查点训练机器人的语义对应**，不会因为维度相同而自动兼容。运行需显式传 `--allow-unadapted-state`。
- 唯一真实图片映射到 `observation.images.camera1`。不复制图片来冒充其他视角；缺失视角由所安装的官方策略处理，若拒绝则保留错误。
- 检查原处理器实际使用的统计键、数值和尺度，不生成伪统计，不任意选择 SO100 数据域来代表 ArmPi。
- 输出保留网络数值与处理器返回数值；只有 canonical 统计检查通过时才提供 `checkpoint_native`。即使统计可用，也仍需另行验证机器人动作语义。

官方依据：[检查点配置](https://huggingface.co/lerobot/smolvla_base/blob/5e8d12a6e2975b0e5e5fce7c8caf47c371d257b6/config.json)、[SmolVLA 使用说明](https://huggingface.co/docs/lerobot/v0.7.0/smolvla)。

## 准备可移植输入包

已有 `tools/record_episode.py` 的检查数据后，在仓库根目录运行：

```bash
python tools/smolvla_probe.py prepare \
  --episode datasets/episodes/<检查目录> \
  --instruction "Pick up the red ball." \
  --out datasets/smolvla_probe/<新目录>/input
```

工具选取最近收到且已对齐的一帧，重新从原始事件计算图片/关节的机器人时间差与接收时间差，均须不超过 0.25 秒；校验完整关节、有限数值、图片 SHA-256 和路径范围。不插值，不制造状态，不覆盖已有输出目录。

输出只有 `camera.jpg` 和 `observation.json`，可复制到模型主机。原始采集日期、时间戳、实际关节顺序、单位和未适配标识均保留。输入属于离线快照，不作为在线控制的新鲜观测。

## 模型主机上的独立环境

```bash

```


```bash
python tools/smolvla_probe.py infer \
  --input datasets/smolvla_probe/<新目录>/input \
  --out datasets/smolvla_probe/<新目录>/result \
  --device cuda \
  --allow-unadapted-state
```

可移植压缩包解压后，可用 `python smolvla_probe.py` 代替上述脚本路径，输入参数使用 `--input input`。

没有 CUDA 时可显式选择 `--device cpu`，该模式不代表满足实时控制需要。离线缓存运行可使用 `--local-files-only`，并设置 `HF_HUB_OFFLINE=1` 禁止底层依赖访问 Hub；缓存不完整会报错。

## SO100 旧坐标约定与夹爪开口（2026-11-20）

## SO100 三维投影拟合与零点歧义（2026-11-20）
