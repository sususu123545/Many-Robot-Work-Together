# 关机后恢复 —— 三步清单

> 适用：ArmPi Pro 任务控制台（`robot_console.html` + 本地代理 `proxy_server(1).py`）

---

## ① 电脑侧（每次开机都要做）

**双击 `启动控制台.bat`**，它会自动：

1. 启动本地代理 `127.0.0.1:8000`（如果已经在跑就跳过，不会重复启动）
2. 打开浏览器到 `http://127.0.0.1:8000`

### 不想用脚本的话，手动也是两步

```bat
cd /d D:\多车协作
"C:\Users\Administrator\.workbuddy\binaries\python\envs\default\Scripts\python.exe" "proxy_server(1).py"
```

然后浏览器地址栏输入 `http://127.0.0.1:8000` 回车。

> ⚠️ **不要双击 `robot_console.html`**。`file://` 协议下页面取视频会跨域失败，必须经本地代理走 `http://127.0.0.1:8000`。
>
> 代理窗口可以最小化。关掉那个黑窗口就停了代理。

---

## ② 页面里（3 步）

1. **「小车 IP」**填当前地址（例如 `10.120.150.178`）→ 点 **「连接」**，左上角变绿点即成功
2. **「画面源」**选 **深度相机RGB /ascamera_hp60c/rgb0/image**
3. 画面若暂时是黑的：它会**每 3 秒自动重试、最多 5 次**，等相机节点起来会自己出现。
   也可以**点一下画面**强制刷新。

---

## ③ 小车侧（只有小车也重启过才需要）

小车**重启后 IP 会变**。先在本机执行这条查新 IP：

```bat
ping raspberrypi
```

能解析出 IP 就说明它在这个网络里。然后启动**深度相机节点**（它是手动启动的，不在开机自启链条里，重启就丢）：

```bat
ssh pi@<小车IP> "docker exec -d -w /home/ubuntu armpi_pro bash -lc 'bash /home/ubuntu/run_ascam_hp60c.sh > /tmp/ascam_run.log 2>&1'"
```

- 密码：`raspberrypi`（**输入时屏幕不显示任何字符**，这是正常的）
- 回车后**没有输出、直接回到提示符** = 正常（`-d` 是后台分离运行）
- 等 5~8 秒，页面画面就会出现

> ⚠️ **三个"静默杀手"**——都不报错，只表现为"什么都没发生"：
>
> | 坑 | 后果 | 规避 |
> |---|---|---|
> | 以 `-u ubuntu` 跑 | ubuntu 不在 `video` 组 → `uvc_open:Access denied` / `open camera, ret: -82` | **必须用 root**（命令里不要加 `-u ubuntu`） |
> | 按路径直接执行脚本 | 脚本没有 x 权限 → `Permission denied` | **必须写 `bash <脚本>`** |
> | 日志写到 root 属主的旧文件 | 重定向在跑脚本前就失败，`-d` 把错误吞掉 | 用 `/tmp/ascam_run.log` 时先 `docker exec armpi_pro rm -f` 清掉 |

### 怎么确认相机真起来了（在车上执行）

```bash
ps -ef | egrep 'ascamera_node' | egrep -v egrep          # 要能看到 ascamera_node
docker exec armpi_pro bash -c 'tail -n 20 /tmp/ascam_run.log'
```

日志里出现这两行才算成功：

```
[ INFO] ...: camera opened
[ INFO] ...: #camera[0x...] SN[ASC60CF22002771]'s firmware version: ...
```

紧接着的 `[stopStreaming] stop streaming` 是**正常的**（没有订阅者时的按需推流），不要据此判定失败。

## 常见问题速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面打不开 | 本地代理没起 | 双击 `启动控制台.bat` |
| 页面能开，但「连接」失败 | 小车 IP 变了 | `ping raspberrypi` 查新 IP |
| 连上了但没画面，角标在数重试 | 该话题没有发布者（相机节点没起） | 拉起相机节点；页面会自己重试 |
| 想看画面但不确定链路 | — | 「画面源」先切到 `/visual_processing/image_result` 验证 |
| 「截图」按钮得到黑图 | **已知问题**：`/snapshot` 每次都是新订阅，命中 SDK 全黑的第 0 帧 | 看实时画面即可；要修需改成 canvas 抓流 |
| 深度图看不到 | web_video_server 编不了 16UC1 | 需要额外加「深度→伪彩→bgr8」节点，未做 |
