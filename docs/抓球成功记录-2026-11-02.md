## 关键过程（可复现的操作要点）

1. 视觉定位：`/grasp/target_base` 给出球在 `arm_base` 系的三维点，配合手眼标定与 FK 使用。
2. 底盘闭环前进：`tmp/analysis/chassis_forward.py`（rclpy，20 Hz 续租 `/cmd_vel`，按 `/odom` 位移闭环，结束后发 `/chassis_control/stop`）。
3. 机械臂受控运动：`tools/perception/make_move_job.py` 生成作业 → `tools/arm_pose_guarded.py --pose ... --source startup` 执行（门禁/限位/步长/温度/回读校验都在容器脚本内）。
4. **关键修正**：机械臂在全伸姿态（径向 ~0.29 m、pitch ≈ −145°）时，关节死区使末端绝对误差可达 ±20 mm，按 FK 目标直接下探会“夹空”。最终有效做法是：
   - 先把夹爪对到球附近（相机实测球在工具系的偏移）；
   - 用**底盘前进 1 cm**（毫米级精度）把球“送进”两指之间；
   - 用大步长（STEP 60–100）强闭合克服夹爪静摩擦卡滞；
   - 闭合停在 331（< 空合拢 377）确认夹到球，再小步抬臂。
5. 夹爪行程实测：张开约 126–166 tick（会间歇卡滞，需要大步长/断电复位），空载合拢 377 tick，夹球 331 tick。

## 现场注意

- 夹爪会间歇性卡滞（张开方向尤其），小步长命令推不动；需 STEP≥60 或断电后手动活动再上电。
- 机械臂在接近全伸的姿态下末端精度差（±20 mm），抓地物优先用“底盘微调 + 短距离下探”。
- 底盘 `enable_motion` 是启动参数（本镜像开机即为 true），`/cmd_vel` 有 0.35 s 看门狗。
- 球被夹住后夹爪舵机会持续出力，注意温度；本次 `r_joint` 31–36 ℃、`joint2` 43 ℃。
