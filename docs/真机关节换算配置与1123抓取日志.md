## A3 刻度

```python
TICK_RAD = math.radians(240.0) / 1000        # 五个臂关节
# r_joint 单独用 180 度 / 1000 tick
def tick_radians(name):
    return math.radians(180.0) / 1000 if name == 'r_joint' else TICK_RAD
```

| 项 | 值 |
| --- | --- |
| 臂关节 | **0.24 °/tick**（240° 对应 1000 tick） |
| 夹爪 | **0.18 °/tick**（180° 对应 1000 tick） |

## A4 换算公式

```python
def tick_to_radians(name, raw):          # 舵机读数 -> /joint_states 的弧度
    _, centre, sign, _, _ = JOINTS[name]
    return sign * (raw - centre) * tick_radians(name)

def radians_to_tick(name, radians):      # 弧度 -> 舵机 tick（带范围检查）
    ident, centre, sign, low, high = JOINTS[name]
    raw = round(centre + sign * radians / tick_radians(name))
    if not low <= raw <= high:
        raise ValueError('Target exceeds hardware limits ...')
    return ident, raw
```

两个式子互为逆运算，**注意 `sign` 在 `radians_to_tick` 里是乘在分子上的**
（因为 `raw = centre + sign·rad/scale` 与 `rad = sign·(raw−centre)·scale` 同构）。
