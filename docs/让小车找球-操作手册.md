# 让小车找球 · 操作手册

> 2026-11-03。目标：球不在相机画面里时，让底盘转着圈找，找到就停。
> 实现在 `robot_agent` 包（`ros2_ws/src/robot_agent`）。

## 先说三条硬约束，不满足就一定找不到

### 1. 球必须是红色的

检测器只认红：HSV `H∈[0,12] ∪ [168,180]`，`S≥75`，`V≥45`
（`red_ball_detector.find_red_sphere`）。橙、粉、紫都不行。

### 2. 球必须离相机 1.58 m 以内

`min_radius_px=6`，`fx=541.286`，球径 35 mm：

```
radius_px = fx × 0.0175 / Z  ⇒  radius_px = 6 时  Z = 1.58 m
```

超过这个距离，球在画面里的半径小于 6 像素，**检测器直接丢掉**。
注意这是到**相机**的距离，不是到车中心的距离——相机装在臂上。

想放宽就调 `min_radius_px`（`2` → 4.7 m，但误检率会上来）。

### 3. 画面里不能有两个大小相近的红物体

`candidates[1].area_px >= 0.72 × candidates[0].area_px` 时判 `ambiguous`，
直接返回"无目标"。现场有两个红色物体（另一个球、红色包装、红标牌）就会卡死在这一条。

## 为什么要"走一步停一下"，不能一直转

检测器的稳定性门：连续 **5 帧**目标中心移动 < 7 px 才算定位成功
（`stability_frames=5`、`stability_center_px=7`）。

0.18 rad/s 转起来，5 帧（0.625 s）目标在画面里移动约 38 px——**门永远开不了**。
所以只能：转 45° → 停 → 等 0.8 s 让车身停稳 → 看 2 s → 再转。
一圈 8 步，约 1 分钟。

底盘还有一层：`MotionLease` 的 `command_timeout=0.35 s`，**0.35 s 收不到
`/cmd_vel` 就自动刹车**。所以节点在转动期间必须持续发布（20 Hz），
发一次就不管的写法会让车转半圈停住。

## 跑

```bash
# 起搜索节点（不会自己动）
ros2 launch robot_agent search_scan.launch.py

# 看状态（另一个终端）
ros2 topic echo /vla/search_status
```

`/vla/search_status` 里先确认这几项：

| 字段 | 期望 | 含义 |
|---|---|---|
| `blocked_reason` | `""` | 非空就是现在动不了，字符串会说明原因 |
| `detection_age_s` | < 0.6 | 检测器在出数（不管有没有球） |
| `detection_reason` | `no_red_sphere` | 没球时的正常值 |

**底盘运动授权必须由人给**，节点不会自己开：

```bash
ros2 param set /chassis_control enable_motion true
```

然后触发：

```bash
ros2 service call /vla/search/start std_srvs/srv/Trigger
```

随时可以叫停（立刻发 5 帧零速，车马上停）：

```bash
ros2 service call /vla/search/stop std_srvs/srv/Trigger
```

## 找没找到怎么读

| `state` | 含义 |
|---|---|
| `observe` | 停着在看 |
| `step` | 正在转（45° 一步） |
| `settle` | 刚停，等车身停稳 |
| `found` | **找到了**，已停车。同时 `detection_valid: true`，`point_camera_m` 有三维点 |
| `exhausted` | 转满 360° 没找到 |
| `aborted` | 中途被打断（急停/硬件故障/超 240 s） |

`found` 之后 `/grasp/target_base` 也会出数（已有的 `grasp_target_transform` 节点），
可以直接接抓取链。

## 会踩的坑

- **`enable_motion` 被拒**：`/chassis_control/status` 里 `estop` 或 `hardware_fault`
  为真时要先 `ros2 service call /chassis_control/reset_estop std_srvs/srv/Trigger`。
  复位后**还需要重新给一次 `enable_motion`**，复位不会自动授权。
- **车打滑但里程计不动**：麦轮在光滑地面会打滑。搜索只靠 `/cmd_vel` 时间积分
  估算转角，实际转角会偏。转不满一圈就 `exhausted` 时，把 `max_sweep_deg` 调大
  （比如 450）再跑一次。
- **球找到了但抓取链拿不到**：`found` 只代表检测器定位成功。抓取还要
  `enable_arm_motion`、臂的 `r_joint` 硬件问题（298~379 tick 卡死）另算。
