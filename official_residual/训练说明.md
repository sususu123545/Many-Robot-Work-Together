# ZSL1：在官方步态基础上训练修正层

训练电脑：sususu。项目目录：`/mnt/llm/quadruped_dev/official_residual`。

MATRiX 官方 XGB 控制器继续负责关节和步态。PPO 学习速度、方向输入的少量修正，直接读取 MATRiX 中 ZSL1 的里程计并收集训练数据。官方随包加密部署模型保持原样；本项目产出的检查点属于新增的修正层，不是官方神经网络的续训权重。

采用已完成关节映射的 ZSL1 模型，保留原模型质量、惯性和外形。每轮 20 秒，包括停止、前进、停止、后退，目标速度在 0.45—0.55 米/秒之间变化。策略每秒运行 20 次，正向输入最多修正 0.10，转向输入最多修正 0.10。训练前后各测试两轮固定 0.50 米/秒的命令。较低输入下官方策略在本模型中接近原地站立，因此采用已验证可行走的速度范围。

训练文件：

- `live_env.py`：实际仿真采样、奖励、命令限幅和遥测保护。
- `train_live.py`：PPO 训练、基线对比、检查点及控制权交接。
- `runs/official_live_v1/manifest.json`：训练方式及官方部署模型校验值。
- `runs/official_live_v1/progress.json`：训练进度。
- `runs/official_live_v1/result.json`：训练完成后的对比结果。
- `runs/official_live_v1/final.zip`：新增修正层的 PPO 检查点。
- `runs/official_live_v1/live-telemetry.jsonl`：实际采集的逐步遥测。

训练期间请保持 MATRiX 仿真运行。每轮会自动重新加载同一个平地场景，核对机器人已回到起点后再采样。脚本会暂时接管本机 UDP 输入，退出后恢复原来的中文桌面控制入口。新修正层不会自动替换默认控制，是否有效以训练完成后的测试结果为准。

继续训练示例（在 sususu 的终端执行；保持官方 ZSL1 仿真已经启动）：

```bash
source /mnt/llm/quadruped_dev/activate.sh
cd /mnt/llm/quadruped_dev/official_residual
python -u train_live.py --steps 8192 --run runs/official_live_v2 --resume runs/official_live_v1/final.zip
```

停止训练可在其前台终端按 Ctrl+C；脚本保存中断检查点并恢复桌面控制。不要同时运行多个训练或控制进程。

结果只代表该平坦场景与本次目标速度下的仿真表现。尚未测试复杂地形和实机。
